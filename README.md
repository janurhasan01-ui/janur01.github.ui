# E-Voting Pilkades Desa Telukbuyung 2026

Paket GitHub Pages untuk simulasi E-Voting. Pada area pemindai hanya ditampilkan tombol **Ganti Kamera**; tombol ini merupakan tampilan saja dan belum menjalankan fungsi perpindahan kamera.

## Upload ke GitHub
1. Buat repository baru atau buka repository yang sudah ada.
2. Unggah `index.html` ke root repository.
3. Pilih **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**, branch `main`, folder `/(root)`, lalu **Save**.

Catatan: ini adalah simulasi/demo, bukan sistem pemungutan suara resmi.
